# Cloudshop — iПринт

## Предложения обновлений и Telegram

Предложения приходят с основного сайта владельца `polaroidstav76-cloud/spravochnik-tovarov` через Edge Function `client-updates`. Клиент согласовывает или отклоняет их в разделе «Обновления». Отдельный логин разработчика не требуется. Согласование не устанавливает программный код автоматически.

Telegram-бот: https://t.me/iprinttipografia_bot. Ежедневная сводка запускается в 21:00 по Москве (cron `daily-report`, 18:00 UTC). Кнопка «Закупка» и команда `/purchase` показывают незакупленные заявки. Отвечает только активным чатам из `report_recipients`; само нажатие Start не открывает доступ к данным. Для тестирования подключён чат, согласованный владельцем при настройке. Перед передачей клиенту нужно добавить её чат и отключить тестовый, если он больше не нужен.

Токен бота и секрет webhook хранятся в Supabase Vault, в репозитории их нет. Конфигурация и данные для Telegram выдаются только серверной роли. Исходники обработчика: `supabase/functions/telegram-purchase`.

Рабочая копия для клиента. Исходный демопроект остаётся отдельным.

- GitHub: iprintast-maker/cloudshop
- Supabase: cvlwoylsdgvwycntyqxu
- Каталог и справочник переносятся из polaroid-demo.
- Выдуманные клиенты, продажи, смены, остатки и учётные записи не переносятся.

Сайт подключён к отдельной базе клиента. Вход обязателен. Публичный ключ в config.js предназначен для браузера; секретные ключи в репозитории не хранятся.

Логин первого администратора: admin. Пароль задаётся владельцем в Supabase Auth, email учётной записи: admin@staff.cloudshop.local.

## Размещение

Команда сборки: `node build.mjs`. Папка публикации: `dist`. Публиковать нужно только содержимое этой папки.

Для локального просмотра: выполните сборку, затем запустите HTTP-сервер в dist, например `python -m http.server 8080 --directory dist`.

## База данных

Папка supabase/bootstrap содержит SQL, использованный при первоначальном переносе. Он уже применён в базе клиента; повторно запускать его на рабочей базе нельзя. Каталог сохранён, шаблоны отчётов очищены от демонстрационных операций. Серверная функция staff-admin управляет сотрудниками после проверки прав администратора.

В Supabase Auth настройте Site URL на адрес опубликованного сайта. Филиалы, сотрудников, ставки оплаты и фактические остатки владелец настраивает под свою организацию.
