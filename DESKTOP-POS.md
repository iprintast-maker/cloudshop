# Айпринт · касса для Windows

Отдельная Windows 10/11 x64 сборка для https://iprintast-maker.github.io/cloudshop/.
Исходный Клаудшоп владельца не изменяется. Приложение использует существующие кассу,
каталог, общую смену и привязку кассира к вошедшему аккаунту Айпринта.

Установка: распаковать ZIP, запустить INSTALL.cmd. Ярлык «Айпринт - Касса».
Программа работает поверх других окон, сворачивается в панель, сохраняет черновик
и избранные позиции. Горячая клавиша Ctrl+Shift+I (не пересекается с Клаудшопом).
Автозапуск включается в настройках.

Изоляция: отдельные exe IprintDesk, mutex, HKCU Run, установочная папка, WebView2
профиль %LOCALAPPDATA%\IprintDesk и ключи localStorage iprint.desktop.*.
Пароли в настройки приложения не записываются. Авторизация отдельна от браузера.
Товары и продажи хранятся в прежней базе Айпринта. Изменения интерфейса активны
только с ?desktop=1; обычный сайт сохраняет прежний вид.

Черновик сохраняет позиции, комментарий, данные клиента, оплату, скидку, разделённую
оплату и галочку «Кассовый чек выдан». Клубная карта проверяется заново. Неопределённый
результат продажи проверяется по номеру заказа на сервере перед восстановлением.
Существующие предварительные расчёты и заказы при получении после перезапуска
нужно продолжить из соответствующей карточки обычного сайта: их черновик не
превращается в новую продажу. Для продажи требуется интернет.

Проверки: tests/desktop-pos.cjs (восстановление/изоляция/кассовый чек/клиент/сбои),
tests/desktop-pos-browser.cjs (реальная разметка Айпринта в Chromium 570×790),
Windows CI (dotnet publish self-contained + запуск --self-test + синтаксис PS).
Сборка/доставка: .github/workflows/desktop-pos-build.yml, release desktop-pos-v0.1.0.
Установка сохраняет профиль при удалении. WebView2 устанавливается только с
проверенной цифровой подписью Microsoft; .NET на ПК клиента не нужен.
