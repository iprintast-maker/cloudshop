АЙПРИНТ · КАССА НА РАБОЧЕМ СТОЛЕ, версия 0.1.0
Для Windows 10/11 x64. Компьютер должен быть подключён к интернету.

УСТАНОВКА
1. Распакуйте весь ZIP в отдельную папку.
2. Запустите INSTALL.cmd. Установка выполняется для текущего пользователя Windows.
3. При необходимости автоматически установится бесплатный Microsoft Edge WebView2.
4. На рабочем столе появится ярлык «Айпринт - Касса».
5. Войдите в программе под своим логином и паролем Айпринта. Это отдельный профиль входа от браузера.
6. Выберите филиал и подключитесь к своей общей смене. Новая отдельная смена при существующей смене не создаётся.

РАБОТА
Нажмите «Открыть продажу», найдите товар/услугу, добавьте количество.
Напечатали следующую часть заказа — добавьте её в ту же продажу.
Звёздочкой ☆ у позиции можно добавить её в быстрые кнопки.
«Поверх окон» закрепляет кассу. «Свернуть» превращает окно в узкую панель.
Ctrl+Shift+I показывает кассу или сворачивает активное окно. Ctrl+F — поиск в кассе.
«Настройки → Запускать вместе с Windows» включает автозапуск для этого пользователя.
«Настройки → Открыть обычный сайт» открывает полный Айпринт в браузере.

ЧЕРНОВИК
Позиции и введённые данные автоматически сохраняются на ЭТОМ компьютере для своего аккаунта.
После перезапуска нажмите «Открыть продажу» для восстановления.
Чужой черновик не переносится в другой аккаунт/филиал. Перенос в новую смену того же филиала потребует подтверждения.
Нажатие «Оформить продажу» остаётся явным действием: приложение само не пробивает и не печатает ничего.
Если после сбоя неизвестно, записалась ли продажа, программа сначала проверит сервер.
Клубная карта проверяется заново, старый баланс не используется без проверки.
Для восстановления оплаты существующего заказа «при получении» откройте сам заказ на полном сайте.

ОБНОВЛЕНИЯ И ДАННЫЕ
Подключение: https://iprintast-maker.github.io/cloudshop/
Касса берётся с сайта Айпринта, товары/цены/отчёты общие. Обновления сайта появляются в программе после перезапуска.
Данные программы: %LOCALAPPDATA%\IprintDesk. Пароли не записываются в настройки приложения.
Не очищайте папку WebProfile, пока есть незавершённые продажи.
Пока оформляется продажа, дождитесь результата перед закрытием.

Приложение пока не подписано платным сертификатом издателя, Windows может запросить подтверждение запуска.
Для удаления: закройте кассу, запустите UNINSTALL.cmd. Сохранённые вход и черновики не удаляются.

Это отдельная программа Айпринта. Устанавливайте её вместо версии Клаудшопа владельца.
